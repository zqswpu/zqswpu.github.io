张全 Quan Zhang

西南石油大学 · 副教授 ｜ 研究方向：计算机视觉 / 智能信号（图像）处理 / 高性能计算 / 计算成像

电子科技大学信号与信息处理博士，中国科学院光电技术研究所联合培养博士；现任西南石油大学副教授（2024.1 至今）。 长期围绕图像处理、计算机视觉，高性能计算和计算成像开展研究， 主持国家科技重大专项子专题、自适应光学全国重点实验室开放课题等科研项目， 并指导学生在 ASC 世界大学生超级计算机竞赛、全国大学生计算机系统能力大赛等赛事中多次获奖。

技能与专长

计算机视觉
单视图 / 单目三维重建、3D Gaussian Splatting、目标检测与多目标跟踪、车道线检测、车辆重识别、晶体 TEM 图像物相划分。
智能信号（图像）处理
地震多次波压制（U-Net / Uformer / GAN / Radon 变换）、反 Q 滤波能量补偿、BM3D 图像去噪、停泵水击信号处理与进液点定位。
高性能计算
CPU-GPU 异构并行算法、CUDA 并行实现（Radon 变换、地震相干体、频率补偿、二维 FFT）、GPU 并行优化、水力压裂裂缝扩展流-固耦合并行模拟；并行计算课程与教材建设；国产 CPU 并行应用挑战赛指导经验。
计算成像
波前探测（相位差法、强湍流下数值稳定性）、相位复原、激光消光层析水含量成像、云场分布测量与层析成像系统、医学超声模拟系统、光学传递函数的 GPU 并行计算。

本栏目为对原页面研究方向、项目与论文内容的归类整理，未新增未经证实的能力描述。
